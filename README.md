# Fleet Assist

Next-generation Fleet Assist prototype and engineering vision document for HDO field operations.

## Contents

- **`index.html`** — the consolidated, four-phase Fleet Assist prototype (Prepare → Execute → Adapt → Close the Day), covering both the Field Leader and Engineer personas. Front-end-only simulation: no backend, live integrations, or real customer data. Live demo via GitHub Pages once enabled (see below).
- **`Fleet Assist Vision.docx`** — the engineering leadership narrative: problem statement, personas, phase-by-phase capabilities, the Smart Live Assist and Pre-Journey Planning deep dives, the operational AI architecture, and success metrics.

## Running the prototype locally

Open `index.html` directly in any browser — no build step or server required.

## Live demo

Once GitHub Pages is enabled on this repository (Settings → Pages → Source: Deploy from a branch → Branch: `main`, Folder: `/ (root)`), the prototype is reachable at:

`https://kushagradhiman.github.io/fleet-assist/`
